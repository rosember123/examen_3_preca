(3) [Sec. 2.4] Sean $z = 3 - 2i$ y $w = 1 + 4i$. Realice las siguientes operaciones y exprese su respuesta en la forma estándar $a + bi$.
8 puntos
i. (4 puntos) $3z - 2w = a + bi$
ii. (4 puntos) $\dfrac{z}{w} = a + bi$
Solución paso a paso:
i. $3z - 2w = 3(3 - 2i) - 2(1 + 4i) = (9 - 6i) - (2 + 8i) = (9 - 2) + (-6 - 8)i = 7 - 14i$. ($a = 7,\; b = -14$).
ii. Multiplicando por el conjugado de $w = 1 + 4i$, que es $\overline{w} = 1 - 4i$:
$$\frac{3 - 2i}{1 + 4i}\cdot\frac{1 - 4i}{1 - 4i} = \frac{3 - 12i - 2i + 8i^2}{1^2 + 4^2} = \frac{3 - 14i - 8}{17} = \frac{-5 - 14i}{17} = -\frac{5}{17} - \frac{14}{17}i$$ Por tanto $a = -\dfrac{5}{17}$ y $b = -\dfrac{14}{17}$.

Solución paso a paso:
Al dividir $2x^4 - 3x^3 + x^2 + 0x - 5$ entre $x^2 + 2$:
1) $\dfrac{2x^4}{x^2} = 2x^2$. Restamos $2x^2(x^2 + 2) = 2x^4 + 4x^2$, quedando $-3x^3 - 3x^2 + 0x - 5$.
